# Rental-Portfolio-Analysis

## Project Overview
This project analyzes residential rental listings to identify
rental price patterns, property-type differences, and
city-level trends.

## Objectives
- Clean and prepare rental data.
- Investigate missing values, duplicates, and unusual values.
- Analyze average rental prices using SQL.
- Perform exploratory data analysis using Python.
- Build an interactive Power BI dashboard.
- Present data-driven findings and recommendations.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- MySQL
- XAMPP / phpMyAdmin
- Power BI

## Dataset
The final cleaned dataset contains 7,684 records and
14 columns.

The dataset includes city, locality, property type,
area, bedrooms, bathrooms, furnishing, area rate, and rent.

## Project Workflow
1. Data cleaning using Python.
2. Exploratory data analysis.
3. SQL-based rental analysis.
4. Interactive Power BI visualizations.
5. Findings and recommendations.

## Analysis
- Average rental price by city.
- Average rental price by property type.
- Distribution of rental prices.
- Identification of unusually large properties.
- Investigation of high-rent listings.

## Limitation
The dataset contains rental listings rather than verified
occupancy or payment records. Actual occupancy, vacancy,
and rent collected cannot be calculated reliably from
this dataset alone.
